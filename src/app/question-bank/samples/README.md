# Question Bank Sample Pack

This folder contains ready-to-import sample question JSON objects for the question bank page.

## How to use

1. Open `/question-bank`.
2. Paste one JSON file content at a time into the editor.
3. Click **Save**.

## Notes

- The question bank currently saves **one question object** at a time.
- The editor also accepts a wrapper shape like `{ "question": { ... } }`.
- These samples cover the main supported question types used in the app:
  - `mcq`
  - `fillInTheBlank`
  - `matching`
  - `sorting`
  - `dragDrop`
  - `categorization`
  - `categorizationv2`
