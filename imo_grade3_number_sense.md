# IMO / IIT Foundation Mathematics: Grade 3
## Topic 1: Number Sense Curriculum Specification

This document defines the curriculum and question pool for **Topic 1: Number Sense** in the Grade 3 Olympiad (IMO) and IIT Foundation track. The topic is divided into 9 micro-skills, with clear sample questions and detailed step-by-step explanations designed for young learners.

---

### Micro-Skill 1: Place Value vs. Face Value in 4-Digit Numbers
* **Description**: Distinguishing between the value represented by a digit based on its position (thousands, hundreds, tens, ones) and its actual value.
* **Core Concept**: 
  * $\text{Place Value} = \text{Digit} \times \text{Position Value}$ (e.g. at hundreds position, value is $\text{digit} \times 100$)
  * $\text{Face Value} = \text{The digit itself}$, regardless of its position.
* **Sample Olympiad Question**:
  > Find the difference between the place value of 7 and the face value of 4 in the number **8,754**.
* **Options**:
  * (A) 696
  * (B) 704
  * (C) 693
  * (D) 746
* **Correct Answer**: (A) 696
* **Step-by-Step Explanation**:
  1. **Identify the place value of 7**: The digit 7 is in the hundreds place. So, its place value is $7 \times 100 = 700$.
  2. **Identify the face value of 4**: The face value of any digit is the digit itself. So, the face value of 4 is $4$.
  3. **Calculate the difference**: Subtract the face value from the place value:
     $$700 - 4 = 696$$
  4. Hence, the correct option is **(A)**.

### Micro-Skill 2: Writing and Reading 4-Digit Numbers (Words & Figures)
* **Description**: Translating numbers between numerical form and word form, especially handling zeros correctly (e.g. "six thousand five").
* **Core Concept**: Zeros act as placeholders. If a place (like hundreds or tens) is not mentioned in words, we write `0` in that position.
* **Sample Olympiad Question**:
  > Choose the numeric representation of the number: **"Seven thousand two hundred five"**.
* **Options**:
  * (A) 7250
  * (B) 7205
  * (C) 7025
  * (D) 7255
* **Correct Answer**: (B) 7205
* **Step-by-Step Explanation**:
  1. **Analyze the parts**:
     * "Seven thousand" $\rightarrow 7 \times 1000 = 7000$
     * "Two hundred" $\rightarrow 2 \times 100 = 200$
     * "Five" $\rightarrow 5 \times 1 = 5$
  2. Note that there are no "tens" mentioned in the words. So, the tens place is filled with a `0`.
  3. **Combine the digits**: 
     $$7 \text{ (thousands)} + 2 \text{ (hundreds)} + 0 \text{ (tens)} + 5 \text{ (ones)} = 7205$$
  4. Hence, the correct option is **(B)**.

### Micro-Skill 3: Expanded Form and Standard Form
* **Description**: Breaking down a number into the sum of values of each of its digits, and recomposing it back to standard form.
* **Core Concept**: $\text{Standard Number} = \text{Thousands} + \text{Hundreds} + \text{Tens} + \text{Ones}$.
* **Sample Olympiad Question**:
  > Which number is represented by: **$5000 + 40 + 8$**?
* **Options**:
  * (A) 5480
  * (B) 5408
  * (C) 5048
  * (D) 5840
* **Correct Answer**: (C) 5048
* **Step-by-Step Explanation**:
  1. **Check each place value**:
     * Thousands: 5000
     * Hundreds: There is no hundreds term, so the hundreds place has a `0`.
     * Tens: 40 (which is 4 tens)
     * Ones: 8
  2. **Add them up**:
     $$5000 + 0 + 40 + 8 = 5048$$
  3. Hence, the correct option is **(C)**.

### Micro-Skill 4: Successor, Predecessor, and Comparing Numbers
* **Description**: Finding numbers immediately after (+1) or before (-1) a given number, and comparing values using $>$, $<$ or $=$.
* **Core Concept**: 
  * $\text{Successor} = \text{Number} + 1$
  * $\text{Predecessor} = \text{Number} - 1$
* **Sample Olympiad Question**:
  > Find the predecessor of the successor of the smallest 4-digit number.
* **Options**:
  * (A) 1001
  * (B) 1000
  * (C) 999
  * (D) 998
* **Correct Answer**: (B) 1000
* **Step-by-Step Explanation**:
  1. **Find the smallest 4-digit number**: The smallest 4-digit number is $1000$.
  2. **Find the successor of 1000**: Add 1:
     $$1000 + 1 = 1001$$
  3. **Find the predecessor of 1001**: Subtract 1:
     $$1001 - 1 = 1000$$
  4. Notice that the predecessor of a successor of any number is simply the number itself!
  5. Hence, the correct option is **(B)**.

### Micro-Skill 5: Building Greatest and Smallest Numbers from Digits
* **Description**: Arranging a set of four distinct digits to form the maximum or minimum possible numerical values, understanding that the highest digit must go to the highest place value.
* **Core Concept**: 
  * For **Greatest**: Sort digits in descending order.
  * For **Smallest**: Sort digits in ascending order. If `0` is a digit, place it in the second position (hundreds place) because a 4-digit number cannot start with `0`.
* **Sample Olympiad Question**:
  > Form the smallest 4-digit number using the digits **4, 0, 8, 3** without repetition.
* **Options**:
  * (A) 0348
  * (B) 3408
  * (C) 3048
  * (D) 3480
* **Correct Answer**: (C) 3048
* **Step-by-Step Explanation**:
  1. **Identify the digits**: 4, 0, 8, 3.
  2. **Sort digits to make the smallest number**: The sorted order is $0, 3, 4, 8$.
  3. **Apply the zero-placement rule**: A number cannot start with 0 (since $0348$ is a 3-digit number). Therefore, place the next smallest non-zero digit ($3$) first, and place the $0$ immediately after it.
  4. The arrangement becomes: **3 (thousands)**, **0 (hundreds)**, **4 (tens)**, **8 (ones)** $\rightarrow 3048$.
  5. Hence, the correct option is **(C)**.

### Micro-Skill 6: Rounding Off Numbers (Nearest Tens & Hundreds)
* **Description**: Approximating numbers to make them simpler while keeping their value close to the original.
* **Core Concept**: 
  * Look at the digit to the right of the rounding place.
  * If that digit is **5 or more**, round up (+1 to the rounding place, fill right with 0).
  * If that digit is **less than 5**, round down (keep the rounding digit, fill right with 0).
* **Sample Olympiad Question**:
  > What is the sum of **342 rounded to the nearest ten** and **567 rounded to the nearest hundred**?
* **Options**:
  * (A) 940
  * (B) 900
  * (C) 910
  * (D) 950
* **Correct Answer**: (A) 940
* **Step-by-Step Explanation**:
  1. **Round 342 to the nearest ten**:
     * The tens digit is 4. The digit to its right is 2 (ones place).
     * Since 2 is less than 5, we round down $\rightarrow 340$.
  2. **Round 567 to the nearest hundred**:
     * The hundreds digit is 5. The digit to its right is 6 (tens place).
     * Since 6 is 5 or more, we round up $\rightarrow 600$.
  3. **Calculate the sum**:
     $$340 + 600 = 940$$
  4. Hence, the correct option is **(A)**.

### Micro-Skill 7: Roman Numerals up to 100
* **Description**: Understanding the seven basic symbols (I=1, V=5, X=10, L=50, C=100) and additive/subtractive rules.
* **Core Concept**: 
  * If a smaller symbol is placed **before** a larger one, subtract it (e.g. IV = 5 - 1 = 4).
  * If placed **after**, add it (e.g. VI = 5 + 1 = 6).
  * Symbols V, L, and D are never repeated or subtracted.
* **Sample Olympiad Question**:
  > Solve the expression and choose the correct Roman Numeral: **$XLIV + XXVI$**
* **Options**:
  * (A) LXX
  * (B) LXVI
  * (C) LXXVI
  * (D) LX
* **Correct Answer**: (A) LXX
* **Step-by-Step Explanation**:
  1. **Convert XLIV to Arabic Numerals**:
     * XL $\rightarrow$ X (10) before L (50) = $50 - 10 = 40$.
     * IV $\rightarrow$ I (1) before V (5) = $5 - 1 = 4$.
     * So, $\text{XLIV} = 40 + 4 = 44$.
  2. **Convert XXVI to Arabic Numerals**:
     * XX $\rightarrow 10 + 10 = 20$.
     * VI $\rightarrow 5 + 1 = 6$.
     * So, $\text{XXVI} = 20 + 6 = 26$.
  3. **Perform the addition**:
     $$44 + 26 = 70$$
  4. **Convert 70 back to Roman Numerals**:
     * $70 = 50 \text{ (L)} + 10 \text{ (X)} + 10 \text{ (X)} = \text{LXX}$.
  5. Hence, the correct option is **(A)**.

### Micro-Skill 8: Even and Odd Numbers Rules
* **Description**: Identifying numbers divisible by 2 (ending in 0, 2, 4, 6, 8) or not (ending in 1, 3, 5, 7, 9) and predicting results of operations.
* **Core Concept**:
  * $\text{Even} + \text{Even} = \text{Even}$
  * $\text{Odd} + \text{Odd} = \text{Even}$
  * $\text{Odd} + \text{Even} = \text{Odd}$
* **Sample Olympiad Question**:
  > If $A$ is an odd number and $B$ is an even number, what type of number is $(A \times B) + A$?
* **Options**:
  * (A) Always Even
  * (B) Always Odd
  * (C) Can be either Even or Odd
  * (D) Cannot be determined
* **Correct Answer**: (B) Always Odd
* **Step-by-Step Explanation**:
  1. Let's substitute simple numbers to test:
     * Choose odd $A = 3$, and even $B = 2$.
     * Calculate $(A \times B) + A$:
       $$(3 \times 2) + 3 = 6 + 3 = 9$$
       $9$ is an odd number.
  2. Let's analyze using math rules:
     * $\text{Odd } (A) \times \text{Even } (B) = \text{Even}$ (multiplying any integer by an even number always yields an even number).
     * $\text{Even } (A \times B) + \text{Odd } (A) = \text{Odd}$ (adding an even and an odd number always yields an odd number).
  3. Therefore, the result is always odd.
  4. Hence, the correct option is **(B)**.

### Micro-Skill 9: Number Patterns and Skip Counting
* **Description**: Identifying rules of progression (skip counts by 5s, 10s, 25s, or custom rules) and finding missing terms.
* **Core Concept**: Find the constant difference ($d$) between consecutive numbers: $d = T_2 - T_1$. Add it to the last term to find the next.
* **Sample Olympiad Question**:
  > Find the missing number in the sequence: **$1245, 1270, 1295, \_\_\_\_, 1345$**
* **Options**:
  * (A) 1310
  * (B) 1320
  * (C) 1300
  * (D) 1315
* **Correct Answer**: (B) 1320
* **Step-by-Step Explanation**:
  1. **Find the pattern rule**: Calculate the difference between consecutive terms:
     $$1270 - 1245 = 25$$
     $$1295 - 1270 = 25$$
  2. The pattern is skip counting forward by $25$.
  3. **Find the missing term**: Add 25 to the third term:
     $$1295 + 25 = 1320$$
  4. **Verify with the next term**: Add 25 to the missing term:
     $$1320 + 25 = 1345$$ (matches the last term!).
  5. Hence, the correct option is **(B)**.
